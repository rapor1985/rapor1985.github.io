Privacy Policy

Last updated: 5 November 2026

Who uses this application

Channel Publisher is a private tool used only by its owner to manage their own YouTube channels (Slumberfall Stories, Placer Sonoro and Lingo on Air). It is not available to other users.

What data is accessed

With the owner's consent through Google OAuth, the application uses the YouTube Data API to upload videos, set thumbnails and subtitles, schedule publication times, add videos to playlists and read the owner's own channel and video information to confirm that uploads succeeded.

How data is stored

Access tokens are stored only on the owner's own computer, in the Windows Credential Manager. No personal data is sold, shared with third parties, or used for advertising.

Google API Services

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
